# AI Rice Factory Automation

AI-powered rice factory management system built with FastAPI, PostgreSQL, React, Gemini AI, and Voice AI.

## Features

- User authentication
- Admin and Staff roles
- Materials management
- Suppliers management
- Buyers management
- Purchases management
- Sales management
- Inventory management
- Production management
- Products management
- Payments
- Receivables and Payables
- Expenses
- Dashboard
- Reports
- AI Chat
- AI Purchase
- AI Sale
- Voice AI

## Technology Stack

### Backend
- Python 3.12+
- FastAPI
- SQLAlchemy
- PostgreSQL
- Psycopg2
- Gemini AI
- SpeechRecognition
- Edge TTS

### Frontend
- React
- Vite
